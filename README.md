Grad student at Columbia studying Quantum Science and Technology. Before this, cybersecurity and network engineering at Purdue. I build things that help software act on someone's behalf without breaking their trust.

### ✦ What I'm building

**Erys** ◇ an ambient macOS agent that watches your work, remembers your commitments, and follows through on them. Screen capture, hybrid search, a voice layer, and an agent that actually does things. [erys.app](https://erys.app)

**Warrant** ◇ a delegation-proof layer for AI agents built on post-quantum signatures. If an agent acts for you, there should be cryptographic proof you allowed it.

**Know** ◇ professional network intelligence for B2B teams, co-founded with a friend. [useknow.io](https://useknow.io)

### ✦ Where I come from

I spent my undergrad in security: incident response at KPMG, vulnerability assessment at DBS Bank, a first-author USENIX Security paper on adversarial attacks against LLM-powered security tooling. That work is why I care about agent trust now. Autonomous software is only useful if you can verify what it did and prove what it was allowed to do.

The quantum degree is the same thread pulled further. Post-quantum cryptography is the foundation the next decade of trust infrastructure gets built on, and I want to understand it from the physics up.
